[![Python](https://img.shields.io/badge/python-v3.7+-blue.svg)](https://www.python.org/downloads/)

[![Code quality: Pylint](https://img.shields.io/badge/code%20quality-pylint-brightgreen.svg)](https://www.pylint.org/)

Um jogo simples de **Shoot 'em up** desenvolvido em Python usando a biblioteca Pygame. O jogador controla uma nave espacial e deve desviar dos inimigos que caem do topo da tela.

## 📋 Funcionalidades

- Movimento da nave com as setas do teclado (← →)
- Inimigos que aparecem aleatoriamente do topo da tela
- Sistema de pontuação
- Botão de saída integrado no jogo
- Reinício automático após colisão

## 🚀 Instalação

### Pré-requisitos

- Python 3.7 ou superior
- pygame 2.0 ou superior

### Passos de instalação

1. Clone este repositório:
```bash
git clone https://github.com/AndersonC75/Game.git
cd Game
```

2. Instale as dependências:
```bash
pip install pygame
```

## 🎮 Como executar

```bash
python Jogo.py
```

### Controles do jogo

- **Seta Esquerda (←)**: Mover nave para a esquerda
- **Seta Direita (→)**: Mover nave para a direita
- **Botão "Sair"**: Sair do jogo

## 📝 Como jogar

1. Execute o jogo seguindo as instruções acima
2. Use as setas do teclado para mover sua nave
3. Evite colidir com os inimigos vermelhos que caem do topo
4. Sua pontuação diminui quando você colide com inimigos
5. O jogo reinicia automaticamente após cada colisão
